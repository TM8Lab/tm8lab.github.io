# TM8 Lab website

Jekyll website using Minimal Mistakes 4.28.1 (air skin), deployed by the existing GitHub Pages workflow from main/root.

Edit index.html for the homepage, products/<product>/index.md for product content, _data/navigation.yml for navigation, and _config.yml for branding. Photos are stored locally in assets/images. Content and images are reused from the owner's Tindie listings with permission.

Build with Ruby/Bundler: bundle install, then bundle exec jekyll serve. Preview at http://127.0.0.1:4000.

Review CONTENT-REVIEW.md for missing facts before publication. Preserve CNAME and existing product URLs. Obtain owner approval of a preview before merging into main. Local tools and generated output are ignored by Git.
